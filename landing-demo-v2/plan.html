怎么做到两周完整交付

关键武器：多 Agent 并行开发——让 AI 编程助手同时推进多个子任务

🚀 多 Agent 并行加速

同一天里启动多个 AI 编程会话并行干活：一个写 MCP server、一个写 install.sh、一个做落地页。等效于 3 倍人力，但只占一人的协调时间。

实际效果 单线串行需要 25-30 天的工作量，并行后压到 10 天。我做总指挥 + 联调 + review，AI Agent 做执行。

⚠️ MCP server 学习曲线

第一个 MCP server 会比预期多花 0.5 天踩坑（Schema 设计、stdio/SSE 选型）。但一旦第一个跑通，剩下两个可以复用模式，效率指数级上升。

对策 Day 2 三个 MCP server 并行启动——第一个先跑通模式，另两个套用，整体时间缩短 50%。

⚠️ 跨平台真机覆盖

Mac / Linux / Win11 三个平台必须真机测试，Win 的 PowerShell 行为差异可能引出意外 bug。

对策 Day 9 专项联调日；GitHub Actions 配自动化测试矩阵，每次 push 三平台并行跑。Win11 用虚拟机或同事真机即可。

✓ 后端注册接口已就绪

Pangolinfo 现有注册接口可直接复用，无需后端配合开发新接口。脚本对接现有 API 即可完成终端内邮箱+验证码+密码注册流程。

影响 这一环节零阻塞、零等待。Day 1 直接开始集成现有接口，不占用主路径任何时间。
