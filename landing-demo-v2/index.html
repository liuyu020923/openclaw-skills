3 种安装方案 · 按需选择

"经验手册"和"工具箱"可以独立安装。两者都需要 API Key 才能拿到真实数据，但各自适合不同用户。

📘
仅 Skills

只装"经验手册"

适合：企业 IT 严格 · 网页端用户 · 想读方法论本身
  • ✅ 纯文本 · 无二进制 · 企业 IT 审查零门槛
  • ✅ 网页端用户唯一选择（Claude.ai / ChatGPT GPTs）
  • ✅ 方法论可读可审计——本身就是知识产品
  • ⚠️ AI 调 API 时自己拼参数，准确率 70-80%
$ curl ... | sh --skills-only
≈ 像装了一位"懂行的顾问"
🧰
仅 MCP

只装"工具箱"

适合：开发者 / 二开团队——只要数据接口，不要方法论
  • ✅ 调用准确率 99%+（Schema 强约束，零拼错）
  • ✅ Token 消耗低——AI 不用每次读说明书
  • ✅ 跨 Agent 通用，写一份所有 Agent 都能调
  • ⚠️ AI 不懂业务方法论，回答较"工具化"
$ curl ... | sh --mcp-only
≈ 像给 AI 配了一台"数据查询机"

注意：三种方案都需要 API Key——Skills 是教 AI 怎么调我们 API 的说明书，最终调用时还是要 Key。 三者真正的差异在于：📘 Skills 适合纯文本部署场景（企业 IT 严格 / 网页端）；🧰 MCP 适合追求精准调用（开发者 / 接口集成）；✨ Both 综合最优（普通用户首选）。

🛠️ 你在用哪个 AI 助手？

就像 App 同时支持 iOS、安卓、鸿蒙——我们支持市面上 9 个主流 AI 助手

🤖
1. Claude Code
官方 CLI · Anthropic
Skills MCP Auto
›
安装方式
将 Pangolinfo Skill 文件夹（包含 SKILL.md）直接拖入项目根目录下的 .skills/pangolinfo/ 文件夹中。
目录
~/.claude/skills/pangolinfo/ # 全局 <project>/.skills/pangolinfo/ # 项目级
提示
Claude Code 启动时自动扫描该目录并渐进式加载 Pangolinfo 能力。MCP server 同步注册到 ~/.claude/mcp.json。
🖱️
2. Cursor
AI IDE
Skills MCP Auto
›
方式 A · 基于规则
复制到项目根目录 .cursorrules 文件，或放在 .cursor/rules/pangolinfo.mdc。
方式 B · 基于 MCP（推荐）
Cursor Settings → Features → MCP，添加 Pangolinfo 的本地命令或 SSE 链接。
脚本自动配置
{ "mcpServers": { "pangolinfo": { "command": "pangolinfo-mcp", "args": ["--stdio"] } } }
⚡
3. Hermes Agent
高自主性本地智能体
Skills MCP Auto
›
全局可用
~/.hermes/skills/pangolinfo # Mac/Linux %USERPROFILE%\.hermes\skills\pangolinfo # Windows
当前项目可用
<project>/skills/pangolinfo/
说明
install.sh 自动检测 Hermes 的 ~/.hermes/ 目录并部署 Skills；MCP server 通过 Hermes config 注册。
🏄
4. Windsurf
AI IDE · Codeium
Skills MCP Auto
›
基于规则
核心执行逻辑和提示词保存为项目根目录 .windsurfrules。
基于 Cascade 工作流
作为独立工具在 Windsurf 的 Cascade 工作流中授权挂载。
MCP 配置
~/.codeium/windsurf/mcp_config.json
💻
5. Cline
VS Code 热门 Agent 插件
Skills MCP Auto
›
基于规则
在 VS Code 工作区根目录创建 .clinerules 文件，写入 Pangolinfo Skill 的系统指令与可执行路径。
基于 MCP（推荐）
通过 Cline 的 Custom MCP Servers 配置挂载 Pangolinfo 服务。
MCP 配置文件
~/Library/Application Support/Code/User/globalStorage/ saoudrizwan.claude-dev/settings/cline_mcp_settings.json
⌨️
6. Codex / OpenCode
CLI 工具
Skills MCP Auto
›
命令安装
codex skill install ./pangolinfo-skill
手动目录
~/.codex/skills/pangolinfo/
说明
install.sh 自动调用 codex skill install 或直接拷贝到目标目录，二选一兜底。
🦀
7. OpenClaw
开源高自主性框架
Skills MCP Auto
›
解压目录
<openclaw_root>/skills/pangolinfo/
注册到 agent.yaml
active_skills: - amazon-niche - competitor-radar - pangolinfo # ← 新增
说明
install.sh 自动修改 agent.yaml 并提示用户重启 OpenClaw 实例。
🌐
8. Claude.ai / ChatGPT
网页端 Project / GPTs
Skills ZIP 上传
›
步骤 1
将 Pangolinfo Skill 文件夹打包为 .zip 文件（脚本自动生成 ~/Downloads/pangolinfo-skills.zip）。
步骤 2
在 Claude 的 Project Knowledge 或 ChatGPT 的 自定义 GPTs 知识库 中上传该 ZIP。
Custom Instructions
请根据附带知识库中的 SKILL.md 调用 Pangolinfo 技能
说明
网页端不支持 MCP，仅 Skills 形态。脚本会自动打包 ZIP 并提示后续手动上传步骤。
🔧
9. 其他 Agent（通用方案）
SKILL.md 标准 · 任意支持 Markdown 挂载的 Agent
Skills 手动
›
安装方式
只要你的智能体支持标准的 SKILL.md 读取或 Markdown 挂载，把 SKILL.md 放置在 Agent 工作上下文中，或在系统提示词中引用该文件路径即可唤醒 Pangolinfo 能力。
脚本兜底
install.sh 选择此项会打印所有已知 Agent 的目录路径清单 + 下载链接，让用户自助安装。
