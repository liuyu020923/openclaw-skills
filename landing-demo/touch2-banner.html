用户复制命令执行的那一刻

脚本第一屏就把 GitHub URL 和 Star 数植入用户视野——哪怕跳过其他所有引导，这行字一定会被看到。

~ — bash

这一屏的引导设计

Banner 里的 Star 数 用 ASCII 边框把数字框出来，视觉上像"勋章"，增加可信度
GitHub URL 全文露出 不是缩短链接，让用户记住完整路径，方便后续手动访问
列出"将要做什么" 化解 curl|sh 的安全顾虑——透明告知所有写入位置
需要回车确认 Y/n 提示让用户有"我在主动操作"的掌控感，不是被脚本绑架
